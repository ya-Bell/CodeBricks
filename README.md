**CodeBricks** — визуальный интерпретатор алгоритмов в виде перетаскиваемых блоков.  
Позволяет собирать простые программы без кода: с переменными, выражениями, условиями и циклами.  
Проект подходит для обучения основам алгоритмизации.

## 🌐 Технологии
- **Kotlin** — основной язык разработки
- **Jetpack Compose** — UI-фреймворк для Android
- **Android SDK** — базовый набор инструментов для Android-приложений
- **Gradle** — система сборки и управления зависимостями


## ☕ Начало работы
### Требования
- Android Studio Meerkat (2024.3.1) или новее
- Android SDK 33+ (проверено с API 35)
- JDK 17+ (проверено с Java 21 LTS)
> Приложение может запускаться на Android 5.0+ (API 21+), но рекомендуется использовать устройства с API 29+ для стабильной работы Jetpack Compose.


## 🛠️ Разработка
### Установка
1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ya-Bell/CodeBricks.git
    cd CodeBricks
    ```
2. Откройте проект в Android Studio
3. Дождитесь загрузки зависимостей Gradle (автоматически)
4. Выполните сборку через Build > Make Project или Ctrl+F9

### Запуск
1. Запустите эмулятор или подключите устройство
2. Нажмите Run > Run 'app' или Shift+F10

### Правила коммитов
Мы используем семантический стиль коммитов:
- `feat`: новая функциональность
- `fix`: исправление багов
- `docs`: изменения в документации
- `refactor`: улучшение кода без изменения логики
- `style`: форматирование, стилистика
- `test`: добавление или изменение тестов

**Пример:**
```bash
feat(variable): support multiple variable declarations
```
> Это помогает поддерживать чистую историю изменений и упрощает командную работу.
